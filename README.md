# SimpleApp: Учебное iOS-приложение для отслеживания криптовалют

## ✨ Основные функции

*   **Список криптовалют**: Просмотр списка популярных криптовалют с ценами и изменением за 24 часа.
*   **Пагинация**: "Бесконечный" скроллинг для плавной подгрузки данных по мере прокрутки.
*   **Детальный экран**: Просмотр подробной информации о выбранной криптовалюте.
*   **Избранное**: Добавление монет в список для отслеживания на отдельной вкладке.
*   **Настройки**: Гибкий экран настроек, который легко расширить.
*   **Кастомный UI**: Весь интерфейс построен программно без использования Storyboard.
*   **Градиентный фон**: Приятный для глаз градиентный фон на всех экранах.

## 🏛️ Архитектура

Проект построен с использованием архитектурного паттерна **MVP (Model-View-Presenter)**, что обеспечивает четкое разделение ответственностей:

*   **Model**: Пассивные структуры данных, отвечающие за представление бизнес-сущностей (`Coin`, `SettingsOption`).
*   **View**: Отвечает исключительно за отображение данных и передачу действий пользователя. Включает в себя `UIViewController` и `UIView`. `View` ничего не знает о бизнес-логике.
*   **Presenter**: Является "мостом" между `Model` и `View`. Получает данные от сервисов (например, `NetworkManager`), форматирует их для отображения и передает во `View`. Также обрабатывает действия пользователя, полученные от `View`.

### Коммуникация между модулями

Для передачи данных между несвязанными модулями (например, с детального экрана на экран отслеживания) используется паттерн **Observer (Наблюдатель)**.

1.  **`FavoritesManager`**: Централизованный Singleton-менеджер, который управляет списком избранных монет.
2.  **`NotificationCenter`**: `FavoritesManager` использует `NotificationCenter` для рассылки уведомлений всем подписчикам о том, что список избранного изменился.
3.  **Подписка**: `TracingPresenter` подписывается на эти уведомления и, получив их, обновляет свой `View`.

Такой подход обеспечивает слабую связанность компонентов и высокую масштабируемость системы.

## 🛠️ Технический стек

*   **Язык**: Swift
*   **Фреймворк**: UIKit (программный UI)
*   **Архитектура**: MVP (Model-View-Presenter)
*   **Сетевые запросы**: `URLSession`
*   **Зависимости**: Проект не использует сторонних библиотек и зависимостей, демонстрируя работу с нативными API Apple.

## 📁 Структура проекта

Проект имеет модульную структуру для удобства навигации и поддержки:

*   **`App/`**: Содержит `AppDelegate` и `SceneDelegate`, точки входа в приложение.
*   **`Builder/`**: Класс-сборщик, отвечающий за создание и конфигурацию модулей.
*   **`Networking/`**: Сетевой слой, инкапсулирующий работу с `URLSession` и API.
*   **`FavoritesManager/`**: Центральный менеджер для управления списком избранного.
*   **`Extension/`**: Глобальные расширения для стандартных классов (например, `UIView+Gradient`).
*   **`Module/`**: Директория, содержащая все экраны приложения, разделенные по функциональности.
    *   **`Market/`**: Модуль для отображения списка криптовалют.
    *   **`Settings/`**: Модуль экрана настроек.
    *   **`TabBar/`**: Кастомный `UITabBarController`.
    *   **`Tracing/`**: Модуль для отображения избранных монет.
